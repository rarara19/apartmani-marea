APARTMANI MAREA — postavljanje sajta na GitHub Pages
=====================================================

U ovom folderu je CEO sajt. Sve ovo ide na GitHub:
- index.html, apartmani.html, galerija.html, cenovnik.html, lokacija.html, kontakt.html
- styles.css, script.js
- folder img/  (sve fotografije)

KORACI:
1) Uloguj se na https://github.com  (nalog: rarara19).
2) Gore desno klikni "+" -> New repository.
   - Repository name: apartmani-marea
   - Izaberi: Public
   - Create repository.
3) Na stranici repozitorijuma klikni: Add file -> Upload files.
4) Otvori OVAJ (otpakovani) folder, pritisni Ctrl+A da oznacis SVE
   (ukljucujuci folder img) i prevuci u prozor za otpremanje.
   -> index.html mora da bude na vrhu repozitorijuma (ne u podfolderu).
   -> folder img MORA da ide gore zajedno (tu su slike!).
5) Dole klikni "Commit changes".
6) Settings -> Pages:
   - Source: Deploy from a branch
   - Branch: main   folder: / (root)   -> Save
7) Sacekaj 1-2 minuta. Sajt ce biti na:
   https://rarara19.github.io/apartmani-marea/

NAPOMENA O SLIKAMA (zasto su ranije "nestale"):
Slike rade samo ako folder "img" ode na GitHub ZAJEDNO sa ostalim
fajlovima i ako se imena ne menjaju (sva su mala slova). To je sve.
